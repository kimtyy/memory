## Micro-Learning 앱 MVP 정의 및 3개월 개발 로드맵

본 계획은 수익성과 개발 용이성을 최우선 가중치로 설정하여, 3개월 내에 시장에 출시 가능한 핵심 기능(MVP)을 정의하고 자원을 배분하는 것을 목표로 합니다.

### 1. MVP 핵심 기능 목록 (Minimum Viable Product)

수익화 모델(구독)의 초기 검증과 사용자 유지율(Retention) 확보에 가장 직접적으로 기여하는 기능에 집중합니다.

| 구분 | 기능 (Feature) | 목표 (Goal) | 수익성/개발 용이성 평가 |
| :--- | :--- | :--- | :--- |
| **Core (필수)** | **콘텐츠 소비 기능** (영상/텍스트 플레이어) | 사용자가 학습 콘텐츠를 끊김 없이 소비할 수 있게 한다. | 높음 (기존 기술 활용 가능) |
| **Core (필수)** | **사용자 프로필 및 학습 추적** | 사용자의 학습 진도와 성과를 기록하여 동기 부여를 제공한다. | 중간 (데이터베이스 설계 필요) |
| **Monetization (핵심)** | **Freemium 모델 적용** (제한된 콘텐츠 무료 / 프리미엄 잠금) | 초기 사용자 확보 및 유료 전환의 기반을 마련한다. | 높음 (구독 모델 검증) |
| **Engagement (보조)** | **단기 학습 플랜** (7일/14일 챌린지) | 사용자의 지속적인 참여를 유도하고 이탈을 방지한다. | 중간 (콘텐츠 설계 필요) |
| **Support (기초)** | **결제 연동 시스템** (Stripe 등) | 안정적인 수익화 시스템을 구축한다. | 중간 (외부 API 연동) |

### 2. 3개월 개발 로드맵 (수익성 및 개발 용이성 기반)

**가중치 설정:** 수익성 (50%) > 개발 용이성 (30%) > 기능 완성도 (20%)

| 단계 | 기간 | 목표 | 핵심 산출물 (Deliverables) | 자원 배분 (주요 담당 에이전트) |
| :--- | :--- | :--- | :--- | :--- |
| **Phase 1: 기획 및 설계** | 4주 | MVP 기능 확정 및 기술 스택 최종 결정 | 최종 UX/UI 와이어프레임, 데이터베이스 스키마, 기술 아키텍처 정의서 | Writer, Designer, Developer |
| **Phase 2: 핵심 기능 개발** | 6주 | Core 기능(콘텐츠 소비, 추적) 및 결제 기능 구현 | 작동 가능한 내부 베타 버전 (Core 기능만 구현) | Developer, Writer |
| **Phase 3: 테스트 및 출시 준비** | 4주 | 베타 테스트 완료 및 마케팅 자산 준비 | 버그 수정 완료, 사용자 피드백 반영, 마케팅용 콘텐츠(랜딩페이지, 소개 영상) 완성 | Editor, Writer, 영숙 |
| **총 기간** | **14주 (약 3.5개월)** | **수익 검증 가능한 MVP 출시** | **Market Ready MVP** | **전체 팀 협업** |

### 3. 자원 배분 계획

| 역할 | 주요 책임 (Focus Area) | 투입 목표 | 주요 의사결정 기여 |
| :--- | :--- | :--- | :--- |
| **Developer** | 기술 스택 구현, API 연동, 데이터베이스 설계 | Phase 2 집중 투입 | 기술적 제약 조건 및 아키텍처 확정 |
| **Writer** | 콘텐츠 기획 및 UX 텍스트 작성, 마케팅 메시지 개발 | Phase 1, 3 집중 투입 | 핵심 가치 제안(VP) 및 사용자 흐름 정의 |
| **Designer** | 브랜드 비주얼 및 앱 내 UI/UX 디자인 | Phase 1 집중 투입 | 사용자 경험(UX) 및 브랜드 톤 정의 |
| **Business (본인)** | 수익화 모델 검증, KPI 설정, ROI 모니터링 | 전체 과정 모니터링 | 개발 우선순위 및 가격 전략 최종 결정 |
