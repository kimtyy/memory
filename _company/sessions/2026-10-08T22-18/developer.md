# 💻 코다리 — 현빈이 정의한 수익성 기반 MVP 기능 목록에 대해, Time-to-Market을 최소화하기 위한 구체적인 실행 단계(Step-by-Step)와 각 단계별 예상 소요 시간을 산출하여 실행 계획(Roadmap) 초안을 작성한다.

## 🚀 MVP 실행 로드맵 초안 (Time-to-Market 최소화 전략)

CEO의 지시에 따라, 현빈이 수익성 분석을 통해 선정하고 가격 전략을 제시한 MVP 기능 목록을 기반으로 **Time-to-Market(TTM)을 최소화**하는 데 중점을 둔 실행 계획(Roadmap) 초안을 아래와 같이 수립합니다.

이 로드맵은 **'핵심 기능 구현'**에 초점을 맞추고, **'단계별로 검증 가능한 최소 기능'**을 정의하여 개발 리스크를 관리합니다.

---

### 🎯 목표 설정: MVP 범위 정의

**최종 목표:** 가장 높은 가치(수익성)를 제공하는 **'핵심 기능군 1번 (Micro-Learning 콘텐츠 접근 및 학습 모듈)'**을 최소한의 노력으로 시장에 출시한다.

**핵심 성공 지표 (MVP 기준):**
1.  사용자가 콘텐츠에 **접근**할 수 있어야 한다.
2.  사용자가 콘텐츠를 **학습**하고 결과를 얻을 수 있어야 한다.
3.  기본적인 **진도 추적**이 가능하다.

### 🗺️ 단계별 실행 계획 (Step-by-Step Roadmap)

본 로드맵은 개발 과정(Kodari의 역할)과 사용자 경험(Designer/Instagram의 역할)을 통합하여 최소한의 런칭을 목표로 합니다.

| 단계 (Phase) | 세부 실행 항목 (Task) | 주요 산출물 (Deliverables) | 예상 소요 시간 (주차) | 담당 에이전트 | 비고 (TTM 최소화 전략) |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **Phase 0: 기반 구축 (Setup)** | 0.1. 최종 기술 스택 및 DB 모델 확정 (개발 메모 활용) | 최종 기술 스택 정의서, 초기 DB 스키마 초안 | 1주 | Developer | 기존 메모(8/19) 활용하여 개발 착수 지연 방지. |
| | 0.2. 핵심 인증/사용자 관리 시스템 구축 (Minimum) | 사용자 로그인/세션 기능 프로토타입 | 1주 | Developer | 복잡한 기능 제외, 핵심 인증에 집중. |
| **Phase 1: 핵심 기능 구현 (Core MVP)** | 1.1. 마이크로 학습 콘텐츠 **접근 모듈** 구현 (Read Only) | 콘텐츠 뷰어(View) 기능 | 2주 | Developer | 외부 콘텐츠 연동에 집중하여 복잡한 콘텐츠 생성은 보류. |
| | 1.2. **기본 학습 모듈** 구현 (퀴즈/간단 정리) | 기본 학습 인터페이스 및 퀴즈 로직 | 3주 | Developer | 가장 기본적인 학습 경험만 제공. |
| **Phase 2: 추적 및 경험 강화 (Tracking & UX)** | 2.1. **진도 추적 시스템** 연동 (학습 완료 기록) | 사용자 진도 DB 모델 및 UI 반영 | 2주 | Developer, Designer | 학습 완료 시점 기록을 핵심 KPI로 설정. |
| | 2.2. **랜딩 페이지/UI 시안** 최종 확정 및 통합 | 최종 런칭 화면 디자인 (Designer 산출물 활용) | 1주 | Designer | 출시 직전에 디자인을 고정하여 개발 병목 해소. |
| **Phase 3: 수익화 통합 (Monetization Hook)** | 3.1. **결제 연동 시스템** (PayPal) 통합 (MVP 기능에 한정) | 결제 API 연동 및 테스트 환경 구축 | 2주 | Developer | 초기에는 가장 단순한 결제 플로우만 구현. |
| | 3.2. **Tiered Pricing** 기능 활성화 (Basic/Pro 전환 로직) | 구독 상태에 따른 기능 제한 로직 | 1주 | Developer | 핵심 기능(Tier 1)에 대한 접근 제어 로직 구현. |
| **Phase 4: 검증 및 출시 (Validation & Launch)** | 4.1. 내부 QA 및 버그 수정 | 최종 QA 리포트 | 1주 | 전 팀 | 기능 간의 연동 오류 집중 검증. |
| | 4.2. **MVP 런칭** | 서비스 배포 완료 | 1주 | 전 팀 | |

### ⏱️ 총 예상 소요 시간 및 전략 요약

**총 예상 소요 시간:** 약 **14주 (약 3.5개월)**

**TTM 최소화 전략:**

1.  **범위 축소 (Scope Reduction):** 초기에는 모든 수익화 옵션(Tier 2, 3) 및 복잡한 커스터마이징 기능을 **완전히 제외**하고, **Tier 1 (Basic Access)** 기능만 완벽하게 구현하는 데 집중합니다.
2.  **기술 우선순위:** 데이터베이스 모델과 핵심 학습 로직(Phase 1)을 가장 먼저 확정하여 개발의 방향을 고정합니다.
3.  **반복 최소화:** 디자인(Designer)과 마케팅(Instagram) 산출물을 개발 초기 단계에 통합하여, 디자인 변경으로 인한 재개발 비용을 최소화합니다.

**다음 단계:**
개발팀(Kodari)은 이 로드맵을 바탕으로 **Phase 0 (기반 구축)**의 세부 기술 설계(DB 스키마, API 정의)를 즉시 시작해야 합니다.
