## 1. 비주얼 시스템 (브랜드 정체성 확립)

MVP의 핵심 가치인 **'깊이 있는 데이터 차별화'**와 **'전문가 포지셔닝'**을 시각적으로 구현합니다.

### 1.1. 최종 브랜드 컬러 팔레트 (Expert Tone)

| 이름 | HEX 코드 | 용도 | 심리학적 효과 |
| :--- | :--- | :--- | :--- |
| **Deep Indigo** | `#1A237E` | 메인 타이틀, 핵심 CTA (전문성, 신뢰) | 깊이, 지성, 권위 |
| **Muted Gold** | `#FFC107` | 강조 요소, 프리미엄 배지 (가치, 희소성) | 고급스러움, 프리미엄 |
| **Slate Gray** | `#424242` | 본문 텍스트, 배경 (안정감, 집중) | 신뢰, 전문성 |
| **Soft Cream** | `#FAFAFA` | 배경, 여백 (가독성, 편안함) | 명료함, 집중 |

### 1.2. 타이포그래피 스타일 (Clarity & Authority)

*   **헤드라인 (전문성 강조):** **Inter Bold** 또는 **Montserrat Black** (강력하고 현대적인 느낌)
*   **본문 (가독성 강조):** **Roboto** 또는 **Noto Sans KR** (명확하고 읽기 쉬운 서체)
*   **스타일 적용:** 헤드라인에는 'Deep Indigo'를, 본문에는 'Slate Gray'를 사용하여 정보의 위계를 명확히 합니다.

### 1.3. MVP 핵심 화면 플로우 (UX Foundation)

MVP의 핵심은 **'데이터의 깊이'**를 사용자에게 직관적으로 전달하는 것입니다.

1.  **Onboarding:** 전문성 기반의 목표 설정 질문 (심리학 기반 UX 반영).
2.  **Dashboard (핵심):** 단순한 트래킹이 아닌, **'데이터 심층 분석 위젯'**을 최상단에 배치하여 즉각적인 통찰을 제공.
3.  **Data Layer Access:** 프리미엄 기능(Deep Data Layer) 접근은 별도의 **'Expert Mode'**로 명확히 분리하여, 일반 사용자에게는 간결함을, 전문가에게는 심층 분석 툴을 제공합니다.

## 2. 기술적 기반 (API 및 구조 검토)

MVP의 핵심 경쟁력은 **'데이터 차별화'**이므로, 이를 뒷받침할 기술적 기반을 검토합니다.

### 2.1. 핵심 API 검토: 데이터 레이어 분리 전략

*   **제안:** 데이터 레이어를 **Public Layer**와 **Expert Layer**로 명확히 분리하여 API 접근 권한을 관리합니다.
*   **Public Layer API:** 기본적인 학습 트래킹 데이터 (저수준 접근).
*   **Expert Layer API:** 복잡한 통계 분석, 예측 모델, 심층 데이터 필터링 기능 (프리미엄 구독자에게만 접근).
*   **기술적 기반:** 사용자 인증(Auth) 시스템을 기반으로, 구독 등급에 따라 API 엔드포인트 접근 권한을 동적으로 제어하는 구조를 설계해야 합니다.

### 2.2. MVP 시안 (핵심 기능 시각화)

**[썸네일 컨셉 3안 재검토 및 적용]**

이전 작업에서 확정된 썸네일 컨셉 중, **'전문가용 포지셔닝'**에 가장 적합한 컨셉을 최종으로 선정하여 MVP 런칭에 적용합니다.

*   **컨셉 A (Focus on Depth):** 복잡한 데이터 시각화에 중점을 둔, 깊은 인디고와 골드 조합. (전문가 타겟)
*   **컨셉 B (Focus on Efficiency):** 번들 옵션과 깔끔한 UI에 중점을 둔, 슬레이트 그레이와 화이트 조합. (대중적 접근)
*   **컨셉 C (Focus on Template):** 모듈/템플릿 판매에 중점을 둔, 구조적인 레이아웃 강조. (템플릿 판매 타겟)

**✅ 최종 MVP 시각화 방향:** **컨셉 A**를 채택하여, **'Deep Indigo'**와 **'Muted Gold'**를 사용하여 **전문가 집단**에게 허브스마트가 단순한 앱이 아닌 **'데이터 심층 분석 툴'**임을 즉각적으로 인지하게 합니다.
