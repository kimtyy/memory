### 📊 KPI 가중치 적용 준비 프레임워크

이 프레임워크는 모든 잠재적 실행 목표(Action Items)를 정량화하고, 세 가지 핵심 가중치(Weighting Factors)를 통해 최종 우선순위를 산출하는 데 사용됩니다.

#### 1. 핵심 가중치 정의 (Weighting Factors Definition)

각 가중치의 측정 기준과 상대적 중요도를 명확히 정의합니다.

| 가중치 | 기호 | 정의 | 목표 반영 영역 | 잠재적 가중치 범위 |
| :--- | :--- | :--- | :--- | :--- |
| **수익성** | $\text{W}_{\text{Rev}}$ | 예상되는 순수익(LTV, 마진) 대비 투입 자원의 효율성. | 재무적 성과 | 0.1 ~ 1.0 |
| **개발 용이성** | $\text{W}_{\text{Dev}}$ | MVP 구현에 필요한 기술적 복잡도 및 시간 투입의 용이성. | 실행 가능성 | 0.1 ~ 1.0 |
| **시장 수요** | $\text{W}_{\text{Market}}$ | 목표 시장의 크기, 성장률, 경쟁 환경 대비 수요의 강도. | 시장 적합성 | 0.1 ~ 1.0 |

#### 2. 목표 및 실행 항목 매트릭스 (Goal & Action Matrix)

SMVT 실행 계획을 기반으로 각 목표에 대해 측정할 항목들을 정의합니다.

| 목표 ID | 실행 항목 (Action Item) | $\text{W}_{\text{Rev}}$ | $\text{W}_{\text{Dev}}$ | $\text{W}_{\text{Market}}$ | $\text{W}_{\text{Total}}$ (가중 평균) | 예상 ROI (Metric) |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| G1 | [SMVT 목표 1] (예: Micro-Learning MVP 개발) | | | | | |
| G2 | [후속 목표 2] (예: 구독 모델 전환 전략 수립) | | | | | |
| G3 | [후속 목표 3] (예: 경쟁사 ROI 분석) | | | | | |
| ... | ... | | | | | |

#### 3. 의사결정 로직 (Decision Logic)

최종 실행 방안은 다음 공식에 따라 결정됩니다.

$$\text{Priority Score} = (\text{W}_{\text{Rev}} \times \text{Metric}_{\text{Rev}}) + (\text{W}_{\text{Dev}} \times \text{Metric}_{\text{Dev}}) + (\text{W}_{\text{Market}} \times \text{Metric}_{\text{Market}})$$

**최종 실행 원칙:**
1.  **가중치 설정:** 각 목표에 대해 경영진이 $\text{W}_{\text{Rev}}, \text{W}_{\text{Dev}}, \text{W}_{\text{Market}}$의 상대적 중요도를 설정합니다. (예: 수익화 목표에서는 $\text{W}_{\text{Rev}}$에 높은 가중치를 부여).
2.  **정량화:** 각 실행 항목에 대해 예측되는 ROI/KPI 지표(Metric)를 설정합니다.
3.  **점수 산출:** 위 공식을 사용하여 각 실행 항목의 우선순위 점수를 계산합니다.
4.  **최적화:** 점수가 가장 높은 실행 항목을 최우선 실행 로드맵으로 확정합니다.
