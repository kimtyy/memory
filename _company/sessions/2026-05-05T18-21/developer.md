## 🚀 Micro-Learning 앱 3개월 개발 로드맵 (MVP 중심)

본 로드맵은 Business에서 확정된 **수익성(60%)**과 **개발 용이성(40%)** 가중치를 기반으로, 핵심 KPI(프리미엄 전환율, MAU 유지율) 달성을 목표로 설정되었습니다.

### 1. 초기 기술 스택 검토 및 선정

개발 용이성 및 확장성을 고려하여, 모바일 앱 개발과 백엔드 API 연동에 최적화된 스택을 선정합니다.

| 영역 | 기술 스택 | 선정 이유 |
| :--- | :--- | :--- |
| **프론트엔드 (앱)** | **React Native (Expo)** | 단일 코드베이스로 iOS/Android 동시 개발 가능. 빠른 MVP 출시 및 유지보수 용이성 확보. (개발 용이성 최대화) |
| **백엔드 (API/DB)** | **Node.js (Express)** + **PostgreSQL** | Node.js는 개발 속도가 빠르고 API 서버 구축에 용이하며, PostgreSQL은 데이터 무결성과 확장성을 보장하여 장기적인 수익화에 대비. |
| **인증/결제** | **Stripe API** | 복잡한 결제 로직 및 보안 문제를 외부 서비스에 위임하여 개발 리스크를 최소화하고 보안을 강화. |
| **데이터 파이프라인** | **Firebase (또는 AWS Amplify)** | 초기 사용자 인증, 푸시 알림, 간단한 데이터베이스 관리를 빠르게 구현하여 핵심 기능 개발에 집중. |

### 2. MVP 기능 정의 (3개월 집중 목표)

MVP는 핵심 가치(학습 및 성과 추적)와 수익화(구독)를 검증하는 데 필요한 최소한의 기능을 포함해야 합니다.

#### A. 핵심 기능 (Must-Have)
1.  **사용자 인증 및 프로필 관리:** 이메일/소셜 로그인, 기본 프로필 설정.
2.  **콘텐츠 제공 시스템:** 사용자가 학습할 수 있는 핵심 강의/모듈 접근 기능.
3.  **학습 추적 기능:** 사용자가 학습한 콘텐츠와 성과를 기록하고 시각화하는 기능 (MAU 유지율 확보의 핵심).
4.  **결제 및 구독 시스템:** Stripe 연동을 통한 프리미엄 콘텐츠 접근 권한 관리.

#### B. 차별화 기능 (Should-Have, MVP 이후 단계)
1.  **심리학 기반 UX:** 학습 동기 부여를 위한 개인화된 학습 경로 추천 알고리즘.
2.  **커뮤니티 기능:** 학습자 간의 상호작용 및 지식 공유 공간.
3.  **고급 분석 대시보드:** 학습 성과와 수익화 지표(LTV/CAC)를 사용자에게 제공.

### 3. 3개월 개발 마일스톤

| 기간 | 목표 | 주요 개발 항목 | 측정 지표 (KPI 연관성) |
| :--- | :--- | :--- | :--- |
| **1개월 차: 기반 구축 (Foundation)** | 기술 스택 환경 설정 및 핵심 인증/DB 구조 확립. | 백엔드 API 엔드포인트 정의 (Node.js/PostgreSQL), React Native 프로젝트 초기 설정, Stripe 연동 테스트 환경 구축. | 시스템 안정성 (에러율 0%), DB 스키마 최종 확정. |
| **2개월 차: MVP 구현 (Core MVP)** | 핵심 학습 및 결제 플로우 구현. | 사용자 인증 및 프로필 기능 완성, 콘텐츠 제공 API 연동, **Stripe 구독 플로우** 구현 및 테스트. | 기능 완성도 80% 달성, 결제 성공률 100% 확인. |
| **3개월 차: 테스트 및 배포 (Testing & Launch Prep)** | 데이터 추적 기능 완성 및 최종 사용자 경험 검증. | 학습 추적 기능(Progress Tracking) 완성, 초기 사용자 그룹 대상 베타 테스트 진행, 성능 및 보안 최종 점검. | **프리미엄 전환율 5% 목표 검증**, MAU 초기 확보. |

### 4. 개발 용이성 및 리스크 분석

*   **개발 용이성 평가:** **높음.** React Native와 Stripe 같은 검증된 외부 라이브러리 및 API를 활용하여 핵심 기능에 집중하므로, 복잡한 시스템 설계 리스크를 최소화할 수 있습니다.
*   **주요 리스크:** 결제 연동(Stripe)의 보안 문제 및 데이터 파이프라인의 안정성.
*   **완화 전략:** 초기 단계에서 외부 전문 서비스(Stripe)를 사용하고, 데이터베이스 설계 시 보안 요구사항을 최우선으로 반영하여 개발 용이성 확보.
