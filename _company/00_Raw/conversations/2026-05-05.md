개발 용이성 및 확장성을 고려하여, 모바일 앱 개발과 백엔드 API 연동에 최적화된 스택을 선정합니다.

| 영역 | 기술 스택 | 선정 이유 |
| :--- | :--- | :--- |
| **프론트엔드 (앱)** | **React Native (Expo)** | 단일 코드베이스로 iOS/Android 동시 개발 가능. 빠른 MVP 출시 및 유지보수 용이성 확보. (개발 용이성 최대화) |
| **백엔드 (API/DB)** | **Node.js (Express)** + **PostgreSQL** | Node.js는 개발 속도가 빠르고 API 서버 구축에 용이하며, PostgreSQL은 데이터 무결성과 확장성을 보장하여 장기적인 수익화에 대비. |
| **인증/결제** | **Stripe API** | 복잡한 결제 로직 및 보안 문제를 외부 서비스에 위임하여 개발 리스크를 최소화하고 보안을 강화. |
| **데이터 파이프라인** | **Firebase (또는 AWS Amplify)** | 초기 사용자 인증, 푸시 알림, 간단한 데이터베이스 관리를 빠르게 구현하여 핵심 기능 개발에 집중. |

### 2. MVP 기능 정의 (3개월 집중 목표)

MVP는 핵심 가치(학습 및 성과 추적)와 수익화(구독)를 검증하는 데 필요한 최소한의 기능을 포함해야 합니다.

#### A. 핵심 기능 (Must-Have)
1.  **사용자 인증 및 프로필 관리:** 이메일/소셜 로그인, 기본 프로필 설정.
2.  **콘텐츠 제공 시스템:** 사용자가 학습할 수 있는 핵심 강의/모듈 접근 기능.
3.  **학습 추적 기능:** 사용자가 학습한 콘텐츠와 성과를 기록하고 시각화하는 기능 (MAU 유지율 확보의 핵심).
4.  **결제 및 구독 시스템:** Stripe 연동을 통한 프리미엄 콘텐츠 접근 권한 관리.

#### B. 차별화 기능 (Should-Have, MVP 이후 단계)
1.  **심리학 기반 UX:** 학습 동기 부여를 위한 개인화된 학습 경로 추천 알고리즘.
2.  **커뮤니티 기능:** 학습자 간의 상호작용 및 지식 공유 공간.
3.  **고급 분석 대시보드:** 학습 성과와 수익화 지표(LTV/CAC)를 사용자에게 제공.
